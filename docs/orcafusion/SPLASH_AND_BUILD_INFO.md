# OrcaFusion launch screen and build information

## Approved behavior
When OrcaFusion starts, display the **full OrcaFusion logo** (orca emblem + stacked **Orca / Fusion** wordmark), not the legacy OrcaSlicer splash branding. Include readable application build information on the startup screen.

## Splash screen fields
- App name: **OrcaFusion**
- Semantic version (example only): `0.1.0-dev`
- Build identifier: short Git commit SHA or CI run identifier
- Build channel: `Development`, `Beta`, or `Stable`
- Optional build date in ISO 8601 format, generated by CI

**Never hardcode or fabricate build metadata.** Populate these from the build system. For development builds, clearly display the dev/beta status.

## Appearance and usability
- Respect dark mode as the default and use the high-contrast logo variant. Provide a theme-compatible variant for light mode.
- Show the full logo at proportional size, preserving transparency and aspect ratio; never stretch or crop the orca.
- Keep build text legible at Windows 100%, 125%, 150%, 175%, and 200% scaling, and on 1366×768 displays.
- The startup display must not hold up the application when assets are missing; use an accessible fallback with text.
- Do not introduce an unnecessary timed delay just to display the splash screen.

## Other branding locations
Use the standalone orca icon for the EXE/installer, Windows shortcuts, taskbar, title bar and GitHub avatar; use the full combined logo for the splash screen, About panel and documentation. Keep legal attribution to the OrcaSlicer upstream project separate and visible in About / licenses.
